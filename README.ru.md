# Hysteria Control

[English version](README.md)

Лёгкая панель для сервера Hysteria 2: пользователи, ссылки и QR-коды подключений, учёт трафика, показатели сервера и клиентская маршрутизация. Панель работает на Flask и SQLite. Docker, Nginx, PostgreSQL и отдельная сборка интерфейса не нужны. Интерфейс доступен на русском и английском языках; шрифты IBM Plex встроены в панель.

## Установка одной командой

Нужны Ubuntu 22.04+ или Debian 11+ с systemd, доступ root, публичный сервер и домен, указывающий на него. Для получения сертификата должен быть доступен TCP/80, для VPN — UDP/443, для панели — TCP/8443 (по умолчанию). Рекомендуется 1 vCPU и 1 ГБ ОЗУ.

Выполните в терминале сервера:

```sh
curl -fsSL https://raw.githubusercontent.com/ilya-sid/hysteria-control/main/install.sh -o /tmp/hysteria-control-install.sh && sudo bash /tmp/hysteria-control-install.sh
```

Установщик спросит домен, адрес электронной почты для Let's Encrypt и логин панели. Он сам загрузит `app.py`, установит Hysteria 2, выпустит сертификат, создаст каталоги, учётную запись и службы, а в конце проверит их работу. При установке создаётся первый VPN-пользователь `primary`. Пароль администратора и ссылка первого подключения появятся в терминале после успешной установки — сохраните их. Пароль панели также записан в защищённом файле `/etc/hysteria-control/panel.env`.

Для установки без вопросов о домене, почте и логине:

```sh
export HC_DOMAIN=vpn.example.com HC_EMAIL=admin@example.com HC_PANEL_USER=admin
curl -fsSL https://raw.githubusercontent.com/ilya-sid/hysteria-control/main/install.sh -o /tmp/hysteria-control-install.sh && sudo --preserve-env=HC_DOMAIN,HC_EMAIL,HC_PANEL_USER bash /tmp/hysteria-control-install.sh
```

По умолчанию устанавливается Hysteria `v2.12.3`; другую версию можно указать переменной `HY2_VERSION`. Если Hysteria уже установлена как служба `hysteria-server.service`, установщик сохранит копию `/etc/hysteria/config.yaml` с отметкой времени и перенастроит службу для панели. Существующие пользователи Hysteria **не переносятся**, и прежние ссылки перестанут работать. Установщик не перезаписывает уже установленную панель.

## После установки

Откройте `https://ваш-домен:8443/`. Пользователей можно добавлять в панели; для каждого доступны ссылка и QR-код. Хотя бы один пользователь должен оставаться включённым, иначе Hysteria не запустится. В именах новых пользователей допустимы латинские буквы, включая заглавные, цифры, `_` и `-`. Имена, отличающиеся только регистром, считаются одинаковыми. Форма смены пароля открывается кнопкой рядом с переключателем темы. SNI должен совпадать с доменом TLS-сертификата.

Если UFW активен, установщик откроет TCP/80, UDP/443 и TCP/8443. Правила сетевого экрана провайдера VPS нужно настроить отдельно. TCP/80 также нужен для продления сертификата. Порт панели можно изменить переменной `PANEL_PORT` при установке.

Проверка служб и журналов:

```sh
systemctl status hysteria-server hysteria-control --no-pager
journalctl -u hysteria-server -u hysteria-control -n 100 --no-pager
```

Сертификат Let's Encrypt продлевается автоматически. После продления обе службы перезапускаются, чтобы применить новый сертификат. Перед ручными изменениями сохраняйте копии `/var/lib/hysteria-control/panel.db`, `/etc/hysteria/config.yaml` и `/etc/hysteria-control/panel.env`.

## Обновление одной командой

После публикации новой версии файлов в ветке `main` этого репозитория выполните на установленном сервере одну команду по SSH:

```sh
sudo bash -c 'set -o pipefail; curl -fsSL https://raw.githubusercontent.com/ilya-sid/hysteria-control/main/update.sh | bash'
```

Команда сама скачает новые файлы панели и шрифтов, проверит код, перезапустит службу и убедится, что страница отвечает по HTTPS. База пользователей, учётные данные VPN, сертификаты и настройки Hysteria сохраняются. При неудачном перезапуске предыдущие файлы панели восстанавливаются. Вопросов при обновлении нет; сама Hysteria не обновляется.

## Маршрутизация и диаграммы

В панели показан накопленный трафик каждого пользователя: круговая и столбчатая диаграммы. Список пользователей сортируется по имени или общему трафику. Иконка настроек справа вверху раскрывает выбор темы, языка и смену пароля администратора. Тема также может автоматически следовать системной настройке устройства. В светлой теме фон однотонный Cloud Dancer с акцентом Cool Blue; в тёмной — чёрный фон с акцентом Persimmon.

Правила маршрутизации работают в экспортируемом **JSON-профиле sing-box**. По умолчанию российские домены и диапазоны IP идут напрямую, остальной трафик — через Hysteria. В профиль входят суффиксы `.ru` и `.рф`, а также наборы российских [доменов SagerNet](https://github.com/SagerNet/sing-geosite) и [IP SagerNet](https://github.com/SagerNet/sing-geoip). В разделе «Маршрутизация сайтов» можно быстро добавить домен, отдельный IP или CIDR-диапазон и выбрать «Напрямую» либо «Через VPN». Частное правило «Через VPN» имеет приоритет над общим обходом российских сайтов. После изменения правил скачайте профиль пользователя заново и импортируйте его в клиент: клиент загружает и кэширует наборы правил.

Раздел маршрутизации также выдаёт [профиль правил Incy](https://docs.incy.cc/en/routing/): JSON-файл или ссылку `incy://` для импорта одним нажатием. Рекомендуемая кнопка «Автообновление правил Incy» добавляет профиль, который Incy обновляет по HTTPS-ссылке со случайным токеном. По этой ссылке доступны только правила маршрутизации, без учётных данных VPN. Импортируйте профиль рядом с уже добавленным подключением Hysteria; само подключение менять не нужно. Кнопка «Применить правила в Incy» выполняет разовый импорт, который после изменений надо повторить. Обычная ссылка `hysteria2://` и её QR-код содержат параметры подключения, но не правила обхода сайтов. v2rayTun и другие клиенты не получат эти правила автоматически из ссылки: в них нужно настроить аналогичное разделение вручную или использовать профиль sing-box в совместимом клиенте. Некоторые подключения скрывают доменное имя от правил; при требовании точной маршрутизации проверьте путь трафика на устройстве.
